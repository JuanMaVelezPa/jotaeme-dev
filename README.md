# jotaeme-dev

Personal site of Juan Manuel Vélez Parra, published at [jotaeme.dev](https://jotaeme.dev). A static site built with [Astro](https://astro.build), in English (`/`, default) and Spanish (`/es/`).

## Commands

| Command           | Action                              |
| ----------------- | ----------------------------------- |
| `npm install`     | Install dependencies                |
| `npm run dev`     | Local dev server at `localhost:4321` |
| `npm run build`   | Build the static site into `dist/`  |
| `npm run preview` | Serve `dist/` locally               |

## Content

All text comes from `src/content/` (`site.json`, `es.json`, `en.json`). These files are copied by hand from a curated content folder in another repository. Do not edit them here. The CV PDFs live in `public/cv/`.
